# 1.6 PI event frames — certified acquisition and recovery

**Status:** ⬜ not started · **Epic:** P1 E05 PI certification · **Spec:** PI01–PI06, §6.4 certification matrix, §4.2 proxy allowlist, ING02 multiple jobs, I1 I2 I8 I9 I12 I13 I15 · **Tests:** T07 T08 T46 + §6.4 matrix · **Depends on:** 1.2, 1.3, 1.5

## Goal
Replace the watermark-only PI pull with a certified adapter: complete paging, durable per-window checkpoints, open-frame tracking, overlap and correction scans, confirmed deletes, batched attribute reads, typed mappings — behind the intake core so user coding survives and nothing is silently skipped.

## Spec requirements covered
- PI01 connection config/tests (DNS, TLS, auth, authz, version, read) separately; installed help is endpoint authority.
- PI02 browse AF, bind identifiers, cache metadata, **batch attribute reads**, preview before activation, no credentials in browser.
- PI03 open frames: sentinel (`9999-12-31`) → `endTime null`, keep raw sentinel; re-poll tracked open frames even before lookback.
- PI04 enumerate every page; page manifest; advance checkpoint only after all captured/quarantined; 500 is a page size.
- PI05 bounded overlap each scan; three recovery paths: 60 s EF poll, 15 min overlap, daily 7-day scan, weekly 90-day scan (defaults); explicit historical replay.
- PI06 deletes need confirmation (source indication or inventory comparison); restart/lease takeover without skips or duplicates.
- §4.2: no unrestricted proxy; allowlist host/routes/methods/size; TLS validation.
- §6.4: >500 frames in a window; frame open longer than lookback; old frame corrected after closure; typed digital states; asset-only mapping; mixed separators; missing attributes; lost auth; restart mid-page; (rate/counter cases in 1.7).

## Current implementation (verified)
- `integration/pi-event-pull.service.ts`: window = watermark→now; `maxCount` 500/200 with **no paging** (I8); watermark always advanced; one HTTP call per attribute (I13); `status:'Open'` on update (B5); no sentinel handling (B6); `rejectUnauthorized:false`; 30 s timeout; no retries.
- `pi-sync-job/pi-sync-scheduler.service.ts`: every minute; interval/lookback; in-memory lock; UI drops `templateName/maxCount` (I15); one job per tenant.
- `pi-proxy/request` open proxy; `pi-browser/:tenantId/request` DTO without validators (I12).
- Real client code exists for EF search, attributes, AF browsing (`PIWebApiService`, `pi-browser.controller.ts`) — reusable.

## Target design
**`PiWebApiAdapter implements Adapter`** (`src/intake/adapters/pi/`)
- `validateConfig`, `testConnection` → separate diagnostics `{dns, tls, auth, authz, version, read}`.
- `discover(kind)` → AF databases/elements/templates/attributes (reuses `PIWebApiService`), cached in `pi_af_elements` with change detection.
- `read(cursor)` for job scope `{scopeType, scopeId, templates[]}`:
  1. window `[cursor.windowEnd − overlap, now)`; `GET …/eventframes?startTime&endTime&searchMode=Overlapped&maxCount=500&startIndex=N` loop until a page returns < 500 (or installed continuation link); `page_manifests` row per page with outcome.
  2. attributes via **streamsets/batch** (`/streamsets/{webId}/value` or batch controller `/batch`) → one or two calls per page; fall back to per-frame only when unsupported (capability flag).
  3. each frame → envelope `kind=interval_event`, `sourceObjectId=WebId`, `sourceRevision = frame.LastModified|hash`, `endTime = null` when `EndTime >= 9999-01-01` (raw sentinel kept in payload), digital states as `{Name, Value, IsSystem}`.
  4. `IntakeService.accept` for every frame; **cursor advanced only after the whole window is accepted/quarantined**; incomplete page → window not checkpointed, job retry with backoff.
- **Open-frame tracker**: `pi_open_frames(tenant, connection, web_id, start, last_polled)`; a separate job kind `pi-open-frame-refresh` (every poll) re-reads these by WebId regardless of window (PI03, T08).
- **Correction scans**: job kinds `pi-rescan-7d` (daily) and `pi-rescan-90d` (weekly) run the same `read` over wider windows; identical content → duplicates (no revisions), changed → revisions (1.2).
- **Deletes**: `pi-inventory-compare` job compares WebIds known in `source_objects` for a window against the source list; missing after a **completed** comparison → `source_objects.state=deleted_confirmed` + retraction envelope (T46); failed/partial query ≠ delete.
- HTTP: TLS verification on; per-connection `allowInsecureTls` flag audited; retries with jitter; 30 s timeout; `Retry-After` honoured.
- **Proxy**: `pi-proxy` removed; `pi-browser/:tenantId/request` keeps a validated DTO and an allowlist of path prefixes (`/assetdatabases`, `/elements`, `/eventframes`, `/streams`, `/streamsets`, `/attributes`), methods GET/POST(batch), response ≤ 5 MiB.
- Multiple jobs per tenant (scopes/templates) via `ingestion_jobs`.

**PI Web API simulator** (`test/simulators/pi-web-api/`): Nest/Express app serving the subset of endpoints with fixtures: 1201 frames across 3 pages with injectable failure on page 3 (T07); an open frame starting 10 days ago that closes on demand (T08); digital-state attributes; `\\Server\DB\Plant\Line` paths; frames with missing attributes; auth toggle (401 on demand); a frame that disappears (T46). Used in CI; the real PI server is used for the certification run recorded in evidence.

## Tests
- **T07 PI paging**: 1201 frames, page size 500, failure on page 3 → no window checkpoint; retry → 1201 unique `source_objects`; manifest shows 3 pages.
- **T08 long open frame**: frame started before lookback; closes → closure captured by open-frame refresh; `EventChanged` emitted; draft recalculation triggered (stub consumer until 2.5).
- **T46 historical deletion**: frame referenced by (later) approval retracted by source → tombstone + proposal; no deletion of event/approval.
- §6.4 matrix: digital states preserved (with T05); asset-only mapping → unit derived; mixed separators resolve; missing attributes → nulls not NaN; lost auth → job `failed` with health `auth_failed`, no cursor move; restart mid-page → no skips/duplicates (kill worker in test); lease takeover.
- Open-frame elapsed never computed to sentinel (T02 end-to-end through adapter).

- If the plant PI cannot be reached from this environment, certification is deferred and marked ⛔ with simulator results only.
